## Worked AI-security scenario rubric

This local deterministic example represents three fictional scenarios tied to
named Module 8 concepts: **Data Integrity**, **Adversarial Attacks**, and
**Responsible AI**. Each public scenario includes `asset`, `threat`, `control`,
and `residual_risk`.

- A complete training-dataset scenario with a relevant integrity control passes.
- A scenario without an asset fails.
- A non-empty but unrelated control is flagged for human review.

The automated checker verifies only structure and a small threat/control
mapping. Human review judges the explanation and residual-risk rationale.
The example does not run or evaluate a real AI model.

Prerequisite: Python 3; no external package or service is required. From the
repository root:

```bash
python3 ./applied-labs/r34-t021/example.py --scenario normal
python3 -m unittest discover -s ./applied-labs/r34-t021 -p "test_*.py"
```

The normal fixture prints `result=pass` for the training dataset scenario.
See [the R34-T021 applied lab](./applied-labs/r34-t021/README.md) for all
fixtures and exact boundary decisions.
