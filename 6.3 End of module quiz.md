## Applied exercise

Use the [infrastructure security rubric exercise](applied-labs/r34-t041/README.md) to check three fictional answers. The fixture includes a server with a matching patch control, a file store with an unrelated patch control, and a report of an unpatched service with no named asset.

From the root of a local checkout, run this command with Python 3 and its standard library.

```sh
python3 applied-labs/r34-t041/example.py
```

```text
smallest-valid: PASS
review-boundary: REVIEW (threat and control do not match the rubric)
missing-asset: FAIL (asset must be non-blank text)
```

This simulation checks for four required fields and a listed threat and control pair. A person must judge the evidence, the reason for choosing the control, and the risk that remains.
