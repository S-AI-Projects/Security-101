## Applied Exercise: Infrastructure Scenario Rubric and Evaluation Experiment

This applied exercise implements an infrastructure scenario rubric checker and benchmarks correctness across three controlled configuration sizes. See [applied-labs/r34-t059/README.md](applied-labs/r34-t059/README.md) for full documentation and code.

### Invocation

```bash
python3 ./applied-labs/r34-t059/example.py
```

### Scope and Limitations

This simulation runs local CPU benchmarks over in-memory scenario dictionaries. It does not measure physical server load or real cloud infrastructure provisioning latency.
