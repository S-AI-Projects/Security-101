## Applied Lab: Security Scenario Rubric (R34-T001)

This lesson includes an executable applied laboratory demonstrating the evaluation of infrastructure cybersecurity scenarios (Asset, Threat, Control, Residual Risk) against structural completeness and relevance rubrics.

- **Lab Directory**: `applied-labs/r34-t001/`
- **Implementation**: [`example.py`](applied-labs/r34-t001/example.py)
- **Unit Tests**: [`test_example.py`](applied-labs/r34-t001/test_example.py)
- **Documentation**: [`README.md`](applied-labs/r34-t001/README.md)

### Invocation and Expected Output
```bash
python3 applied-labs/r34-t001/example.py --scenario normal
# Expected output:
# {
#   "status": "PASS",
#   "message": "Scenario is complete and internally consistent."
# }
```

### Scope and Limitations
This example validates structural consistency and basic relevance using local heuristic rules. It does not replace qualitative human security risk assessments or dynamic vulnerability scanning.
