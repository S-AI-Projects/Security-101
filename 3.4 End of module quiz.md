## Applied Exercise: Network Security Scenario Rubric (Dual Approach Comparison)

This applied exercise provides a network security scenario rubric checker comparing a direct programmatic evaluator against an independent declarative table. See [applied-labs/r34-t060/README.md](applied-labs/r34-t060/README.md) for full implementation details.

### Invocation

```bash
python3 ./applied-labs/r34-t060/example.py
```

### Expected Output

```text

[FAIL] Missing asset network scenario: Missing required field: asset

Comparison of Direct vs Independent Approaches:
Scenario 'Corporate VLAN Gateway': Direct=PASS, Independent=PASS (Matches: True)
Scenario 'Missing asset network scenario': Direct=FAIL, Independent=FAIL (Matches: True)
```

### Scope and Limitations

This example uses local mock data to compare evaluation approaches. It makes no claims about hardware router behavior or real WAN traffic filtering.
