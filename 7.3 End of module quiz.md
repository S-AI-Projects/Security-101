## Applied Exercise: Data Security Scenario Rubric Checker

This applied exercise provides a runnable local rubric checker and worked regression example for data security threat modeling. See [applied-labs/r34-t055/README.md](applied-labs/r34-t055/README.md) for full implementation details.

### Invocation

```bash
python3 ./applied-labs/r34-t055/example.py
```

### Worked Fixture and Expected Output

- **Customer PII Database**: Complete scenario -> `[PASS]`
- **Missing asset data scenario**: Missing asset -> `[FAIL] Missing required field: asset`
- **Mismatched data protection control**: Re-identification paired with snapshot replication -> `[FLAG_REVIEW] Control appears unrelated to threat; flagged for human review`

Expected output:
```text
Scenario mode: normal
[PASS] Customer PII Database: Scenario meets structural rubric requirements
[FAIL] Missing asset data scenario: Missing required field: asset
[FLAG_REVIEW] Mismatched data protection control: Control 'Deploy storage volume snapshot replication to secondary region' appears unrelated to threat 'Re-identification of anonymized patient health records'; flagged for human review
```

### Scope and Limitations

This tool performs structural validation and keyword-based consistency checks on local mock data. It does not perform live cryptographic audits or automated AI risk evaluations.
