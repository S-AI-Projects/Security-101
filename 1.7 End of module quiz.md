## Applied Lab: Cybersecurity Risk Scenario Checker

### Related lesson
**1.3 Understanding risk management**

### Objective
This lab demonstrates how to identify assets, threats, controls, and residual risks using three fictional cybersecurity scenarios.

### Fictional scenarios

**Scenario 1: College portal**
- Asset: Student records
- Threat: Unauthorized access
- Control: Access control and multi-factor authentication
- Residual risk: An authorized account could still be misused.

**Scenario 2: College email**
- Asset: College email accounts
- Threat: Phishing
- Control: Email filtering and awareness training
- Residual risk: Some phishing emails may still reach students.

**Scenario 3: Computer lab**
- Asset: Lab computers
- Threat: Physical theft
- Control: Password awareness training
- Residual risk: Computers may still be stolen.

### Run the simulation

From the repository root, run:

```bash
python3 applied-labs/r34-t031/example.py
```

Run automated tests:

```bash
python3 -m unittest discover -s ./applied-labs/r34-t031 -p "test_*.py" -v
```

Compare expected and actual results:

```bash
python3 applied-labs/r34-t031/compare_results.py
```

### Simulation disclaimer
This is a local educational simulation using fictional scenarios and predefined keyword checks. It does not scan networks, detect real attacks, or evaluate actual security systems. A REVIEW result indicates that human assessment is needed. The checker evaluates structural completeness and basic control relevance, not the quality of a full risk assessment.
