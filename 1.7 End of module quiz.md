## Applied Exercise: Security Scenario Rubric Checker

This applied lab provides a runnable local rubric checker for cybersecurity scenario evaluations as covered across Module 1. See [applied-labs/r34-t051/README.md](applied-labs/r34-t051/README.md) for full documentation and code.

### Invocation

```bash
python3 ./applied-labs/r34-t051/example.py
```

### Fixtures and Expected Output

The script evaluates three fictional scenarios:
1. **User credential store** (Complete): Contains asset, threat, control, and residual risk. Result: `[PASS]`
2. **Missing asset scenario** (Incomplete): Asset is blank. Result: `[FAIL] Missing required field: asset`
3. **Mismatched control scenario** (Inconsistent): Pairs SQL injection with offline backup. Result: `[FLAG_REVIEW] Control appears unrelated to threat; flagged for human review`

Output:
```text
Scenario mode: normal
[PASS] User credential store: Scenario meets structural rubric requirements
[FAIL] Missing asset scenario: Missing required field: asset
[FLAG_REVIEW] Mismatched control scenario: Control 'Deploy automated offline data backup service' appears unrelated to threat 'SQL injection via search input'; flagged for human review
```

### Simulation Scope and Limitations

This tool provides deterministic structural checking and heuristic validation using local mock data. It makes no claims of AI evaluation or real cloud service security guarantees. Qualitative judgment of control adequacy and residual risk must be performed by human reviewers.
